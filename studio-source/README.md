# AVHS Global Leadership Academy · IB Learning Studio

Public teacher-learning edition, built with React 19 and Vite 6. Run `npm ci`, `npm run check`, and `npm run build`. Deploy only `dist/`. Relative asset paths support GitHub Pages project subdirectories.

## Included

Monday/Tuesday presenter hub and direct activity launchers, subject pathways, DP core, MYP planning and ATL, research reading room, curated teaching summaries, recruitment workspace, and personal-project supervisor/lead-teacher preparation.

Black and Vegas gold form the studio palette, with blue accents. The school/academy text hierarchy is grounded in the official school page; this is a design interpretation, not an official color specification. No school logo assets are copied.

## Personal project

Original criterion-aligned summaries and coaching tools, not a marking rubric or student tracker. Based on the Personal project guide first assessed in 2022, updated April 2023. Confirm current-session guidance in My IB and current school procedures before assessment. No local deadlines are represented as verified. No restricted guide, complete rubric, student work, marks, or private document links are included.

## Privacy and access

Planning inputs remain in browser-tab memory, survive internal navigation, and clear on reload or close. Download or print to retain them. No app analytics, external fonts, student-data integration, browser storage, or app network requests. External sites have separate access, account, and privacy terms. Do not enter student or confidential information.

## Interaction and accessibility

Calm view and reduced-motion styling disable animation. Short transitions use opacity and transforms. The decorative animated sculpture has been removed. Repeated cards avoid backdrop blur. Search inputs update independently from deferred result filtering. Keyboard-visible focus, role/criterion controls, source labels, and phone layouts are included.

## Teaching diagrams

Original React diagrams for MYP ATL (five categories, ten clusters), TOK (five areas of knowledge and four shared lenses, with pairwise comparisons), and the iterative MYP Design cycle. These are teaching aids, not official graphics or assessment rubrics. MYP Design A–D is explicitly distinguished from Personal Project A–C. Complete text alternatives and downloadable teaching guides contain the same original prompts. Official public sources are linked; the older ATL mapping source is labeled.

The home page prioritizes the November 9–10 sessions, followed by teaching diagrams and a concise resource index. Sidebar groups separate facilitation, planning and reading. No additional hosting or audience changes are included.
