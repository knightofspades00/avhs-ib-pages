# AVHS IB Learning Studio

Public teacher-learning edition. React 19 / Vite 6. Run npm ci, npm run check, npm run build. Deploy dist/. Relative asset base supports GitHub Pages subpaths.

No private school documents, calendars, source maps, credentials, or student records. Inputs remain in browser-tab memory; download or print to keep them. No app analytics or network requests. External resources have separate access terms. Research applications are editorial adaptations, not IB-tested effects.
